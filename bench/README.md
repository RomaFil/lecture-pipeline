# bench — стенд нічних експериментів декодування

Не частина конвеєра. Автономний прогін варіантів whisper на повних лекціях
(на VPS: `~/lectures/_thread_test/validate3/`), з пріоритетом проду.

- `runner.sh` — запускається cron'ом кожні 10 хв (`# validate3-...`); flock, стан у
  `RUN.status`/`RUN.attempts`, повтори, аварійний стоп по RAM/зависанню/таймауту,
  звіт у телеграм, наприкінці сам прибирає свій cron-рядок. Не стартує раніше
  `NOT_BEFORE`, поки в `incoming` щось лежить, і бере `.process.lock` конвеєра.
- `run_transcribe.py` — один прогін бойового `process.transcribe()` у своїй сесії.
- `runs.conf` — `RUN BATCH SHA`; аудіо — `_thread_test/audio/<sha>.wav`.
- `qa3.py` — втрати по словах проти старого транскрипту і проти режиму E,
  вади через `transcript_quality`, петлі всередині рядка, пам'ять, коефіцієнт.
- `align2.py` — вирівнювання по словах (validate2, 29.09.2026).

Еталонні транскрипти (`base_<sha>.md`) і `sil_<sha>.txt` у репо не кладуться:
перші — з vault (особисті записи), другі генеруються
`ffmpeg -af silencedetect=noise=-30dB:d=0.5`.
Урок 28.09: якість оцінювати лише вирівнюванням по словах на повних лекціях —
«дірки між таймкодами» і 10-хв кліпи вже двічі дали хибний висновок.
Деталі — lecture-pipeline.md у vault.
